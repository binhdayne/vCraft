# Local fonts

Noto Serif Variable and Noto Sans Variable, distributed by Fontsource 5.3.0 under the SIL Open Font License 1.1. License files are included alongside the fonts.

Source packages: `@fontsource-variable/noto-serif@5.3.0` and `@fontsource-variable/noto-sans@5.3.0`.

Only Latin, Latin Extended and Vietnamese subsets are included, with normal/italic styles and variable weights. The CSS unicode ranges are preserved from the packages. Fonts are served from this application; no Google Fonts request or external font CDN is required.
